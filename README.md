# Zero 1 - Advanced AI Agent Platform

تم التطوير بواسطة **مصطفى عبدالله**

منصة ذكية متقدمة لإدارة المحادثات مع وكيل AI متطور بقدرات تفكير منطقي عالية.

## المميزات ✨

- 🤖 وكيل AI متقدم بوضع تفكير أقصى
- 💾 حفظ دائم لجميع المحادثات
- 🎨 واجهة Dark Theme احترافية
- 📱 تصميم متجاوب (Responsive)
- 🔒 أمان عالي وخصوصية كاملة
- ⚡ أداء سريع جداً
- 🎯 نماذج ذكية (Zero 1)

## التثبيت

```bash
git clone https://github.com/hackzynx-oss/Zero-1-Agent-Platform.git
cd Zero-1-Agent-Platform
npm install
cd client && npm install && cd ..
```

## البدء السريع

```bash
cp .env.example .env
npm run dev
```

## الأوامر الخاصة

- `4040` - عرض جميع المحادثات المحفوظة بالتفصيل

## التكنولوجيا المستخدمة

- React 18 + TypeScript + Vite
- Node.js + Express
- SQLite Database
- Tailwind CSS
- Socket.io (Real-time)
